# Security

Report vulnerabilities privately to the repository owner through GitHub's private
vulnerability reporting when available, or contact the owner before disclosing
sensitive details. Never post HA tokens, cookies, configuration backups, personal
location choices or raw provider captures in an issue. Use synthetic examples and
sanitized error categories. For ordinary bugs, include Core/integration versions and
steps to reproduce without personal data.

The integration needs no credentials and offers no service-mutating operations.
An HTTP 401/403 is an access failure, not a prompt to supply account credentials.
